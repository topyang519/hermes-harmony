# Harmes 界面动效

0.6.6 的动效沿用用户指定的 [apple-design skill](https://github.com/emilkowalski/skills/blob/main/skills/apple-design/SKILL.md)，以短、可打断的反馈为主。参数集中在 `app/entry/src/main/ets/util/AppMotion.ets`。

| 场景 | 默认效果 | 减少动态效果 |
| --- | --- | --- |
| 按钮与点击控件 | 按下缩放至 0.97、透明度 0.86，阻尼为 1 的短弹簧复位 | 80 ms 明暗反馈，无缩放 |
| 页面进入与返回 | 280 ms，前进从右进入，返回沿同一路径退出 | 120 ms 淡入淡出，无位移 |
| 弹窗与录音提示 | 小幅缩放、12 vp 位移及透明度过渡 | 100 ms 淡入淡出 |
| 会话操作、高级设置与状态面板 | 8 vp 轻量入场；展开布局短过渡 | 淡入淡出，布局立即更新 |
| 消息、发送按钮与命令切换 | 轻量入场，消息不会随 token 重播动画 | 短淡入淡出 |
| 日夜主题 | 220 ms 配色过渡 | 100 ms 配色过渡 |

## 操作与生命周期

- 控件使用 ArkUI 原生 `stateStyles` 响应按下，不新增触摸拦截，不等待动画结束再执行点击。
- 文本消息和命令保持系统长按选择；录音沿用原有按住、滑动取消、松开发送手势。
- 不在聊天根布局设置隐式布局动画，键盘仍使用窗口 RESIZE 避让。
- 会话行使用稳定标识，标题与预览单独读取网关版本变化；流式消息只在插入时过渡。
- 设置中的减少动态效果偏好会保存。系统 API 23+ 支持读取和监听系统偏好，早期系统使用应用偏好；监听在 Ability 销毁时注销。
