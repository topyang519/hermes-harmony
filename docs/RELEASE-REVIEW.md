# 0.6.8 发布审查与修复

本次以手机 0.6.7 的最终源码为基础，升级到 0.6.8 / code 39；Python 连接器从 0.3.7 升级到 0.3.8。GPT-6 Luna 子代理分别审查并修复安装器、Python 网关和手机客户端，发布负责人整合结果并独立检查发布文件。

## 问题与执行方案

| 问题 | 方案与结果 |
| --- | --- |
| 安装器与手机指南依赖个人服务器下载 | 迁移至 GitHub Releases，提供 macOS/Linux 与 Windows 安装器，下载固定版本 wheel，安装前检查 SHA-256 |
| 公开文档和 iOS 预置个人地址、部署及设备记录 | 重写公开安装/交接文档，删除旧计划、备份说明与中间预览，iOS 新安装默认空网关 |
| 旧 Git 历史可能保留个人资料 | 只导出最终产品文件建立全新公开历史，提交使用项目通用身份 |
| 个性化调试签名含账号/设备材料 | 发布未签名 release HAP，安装者使用自己的签名；个人签名只留在本地 |
| Hermes URL 凭据可能出现在日志/health | 只报告 URL origin，连接异常只记录类型，加入回归测试 |
| 设备会话状态默认文件权限宽松 | POSIX 目录 0700、文件 0600；Windows 使用账户 ACL，避免错误套用 POSIX 权限导致无法启动 |
| 中继消息 ID 未严格验证 | 限定小写十六进制 ID，拒绝错误类型，避免异常关闭连接 |
| 配对配置接受布尔端口或无效 URL 端口 | 加强配置类型和端口校验，保留有效旧配对 |
| Linux 服务更新后仍运行旧进程 | daemon reload 后 try-restart，再启用服务 |
| 手机部分连接入口与设置校验不一致 | 共用网关校验，限制明文 WS 为本地网络，校验保存失败与连接生命周期 |
| iOS 使用旧 token 字段而新版网关要求 password | 使用 password 查询/X-Hermes-App-Password，保留 Keychain 旧存储键以迁移用户配置 |
| iOS旧连接回调影响新连接/重连缺失 | 连接代次隔离、前台重连、握手 continuation先安装、后台与主动断开取消重连 |
| iOS Keychain先删除再保存可能丢失凭据 | 改为更新已有条目并检查保存状态 |
